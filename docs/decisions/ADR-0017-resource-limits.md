# ADR-0017: Resource limits

Status: Accepted
Date: 2026-11-24
Supersedes: none
Superseded by: none

## Context

Typcast reads local assets, copies them into a compiler workspace, and passes
raw Typst through to the compiler. Without limits, a single document can
consume unbounded memory and disk.

The earlier baseline proposed limits but left the final values open, and it was
unclear whether the raw limit was configurable and where it was enforced.

## Decision

Use fixed limits with one configurable exception:

| Limit | Value | Configurable |
|---|---|---|
| Raw node size | 1 MiB | Yes, through `max_raw_bytes` |
| Asset path length | 1024 characters | No |
| Image file size | 50 MiB per file | No |
| Module file size | 10 MiB per file | No |
| Total copied assets | 500 MiB per compilation | No |

Enforcement rules:

- The raw limit is enforced during validation at `build()` and again before
  emit, so an oversized raw node is rejected before it reaches the compiler.
- The asset limits are enforced before the file is fully read, where practical.
- A violation produces `TYPCAST-VAL-0010` for raw content and
  `TYPCAST-IO-0004` for assets, with the limit recorded in `details`.
- Limits are part of the validated contract. Changing a limit requires a
  schema and emitter review.

## Consequences

- A document cannot exhaust memory or disk through raw content or assets.
- The limits are documented, testable, and identical in Python and TypeScript.
- The raw limit is the only knob, because raw content is generated by the
  caller and is the most likely source of accidental large payloads.
- Applications that need larger limits must change the configuration or wait
  for configurable asset limits in a later version.

## Alternatives considered

| Alternative | Reason rejected |
|---|---|
| No limits | A single document could exhaust the host process. |
| All limits configurable | More configuration surface and more parity combinations to test. |
| Only a total size limit | A single oversized file still slips through. |
| Enforcing limits only in the compiler | The compiler fails late, with poor diagnostics. |
